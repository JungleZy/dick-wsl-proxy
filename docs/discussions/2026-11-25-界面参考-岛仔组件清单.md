# 界面参考：岛仔（Daozai）组件清单

参考对象：GitHub `Renly1994/xiaotang-daozai`，提交 `14eaf70`。依据是 README 展示图（`docs/images/readme/*.webp`）和 `src/paint.rs`、`src/theme.rs`。只记组件长什么样、怎么交互，不涉及配色方案的取舍，也不是实现计划。

岛仔用 egui 自绘，本项目桌面端用 gpui-kit，代码不能复用，只能照形态重做。

## 共同规律

- 形状只有两种：全圆角胶囊（圆角 = 高度的一半）和正圆。
- 不画边框，层次只靠底色深浅区分。
- 每个可点的东西都有两种反馈：悬停时底色渐变提亮（有过渡，不是瞬间切换），按下时整体缩小。
- 一屏只突出一个主角（大数字或主按钮），其余元素压暗、缩小。
