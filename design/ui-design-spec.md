# WSL Proxy UI 设计规范

## 文档范围

本规范描述 Windows 桌面端（`desktop/`，基于 `gpui-kit 0.10.0`）现在的界面：窗口外壳、首页、环境、规则、连接、日志、设置六个页面，以及对话框和托盘。内容以界面代码为准整理；规范和代码对不上时，以代码为准。

色板、固定像素尺寸和界面文案直接取自代码；按 rem 计算的间距、圆角、控件高度是按 gpui-kit 0.10.0 源码换算的。两类都没有在 Windows 上实测或截图核对。标了「需截图确认」的项来自组件库默认值，以实机画面为准。

下面这些早期设计材料只作参考，不代表现状。窗口尺寸、侧栏、字号、首页布局、环境页、连接页、设置页都和现状不同，与本规范冲突时以本规范为准。

## 设计原则

- 首页回答三件事：现在有没有在保护、保护的是哪个发行版、链路是否正常，并给出唯一的下一步操作。
- 所有页面使用同一套字号、间距、颜色和控件规则。
- 所有文字同一字号；应用标题是唯一加粗的文字，层级靠颜色、留白、边框和位置表达。
- 状态集中在底部状态栏：一组五个状态图标，加上用图标区分的实时速率和累计流量，悬停显示完整说明。
- 配置直接在页面填写，个人使用场景允许明文查看住宅配置，数据由 SQLite 保存。
- 每页只保存本页的内容，保存结果只显示在发起保存的那一页。
- 有亮色、暗色两套主题，在标题栏切换。
- 没有真实数据时显示空态，不显示示例数据或猜测的状态。
- 页面结构保持克制，避免重复状态、重复标题和无实际作用的装饰。

## 视觉变量

白天主题取「雾绿 `#DDE7DF` + 森林绿 `#1B412D`」，黑夜主题取「黑 `#080808` + 透白 `#DADADB`」，两套共用亮绿 `#47C86D` 作强调色。亮绿放在白底上做文字太浅（对比度约 2.3:1），所以白天的主按钮和选中文字用森林绿，亮绿只用在浅底、图表和状态图标上；黑夜的主按钮是亮绿底、深色字。正文、按钮和标签文字在两套主题下的对比度都不低于 4.4:1。

### 字体

- UI 字体 `Inter`；数值、地址、端口、路径、时间、速率和流量、版本号、协议用等宽字体 `IBM Plex Mono`。输入框里的文字不用等宽字体。
- 程序不打包字体，代码也没有指定回退字体：本机没装这两种字体时，由系统回退字体显示，中文由系统中文字体显示。实际显示的字体需截图确认。
- 所有文字 12px，包括应用标题、页面文字、卡片标题、按钮（含小号按钮）、输入框、下拉框、标签、悬停提示和对话框标题。已知的例外都在首页流量图上，由图表组件固定：坐标轴刻度 10px，悬停时显示的数值 0.75rem ≈ 10.3px。
- 应用标题 `WSL Proxy` 加粗，是唯一加粗的文字；其他文字都是常规字重，对话框标题也是。
- 不通过字号或加粗制造卡片内的层级差异，使用颜色、留白、边框和位置表达层级。

### 尺寸和间距

间距、圆角和组件库控件的高度按 rem 计算。界面把 rem 设为 12 ÷ 0.875 ≈ 13.71px，让组件库按 0.875rem 排版的正文正好是 12px；所以这些值都不是整数像素。窗口、标题栏、侧栏、导航项、状态栏、表格行高和图标是固定像素。

| 标题栏高度 | 42px |

| 导航项 | 高 40px，左右内边距 6px |

## 应用外壳

### 标题栏

标题栏横跨窗口全宽，`surface` 底，底边 1px `line`。

- 左侧是 23px 盾牌应用图标（`accent`）和 `WSL Proxy` 标题，这一段可以拖动窗口。
- 右侧依次是主题切换、最小化、关闭。主题切换是只有图标的按钮：亮色主题显示月亮，悬停提示「切换到黑夜主题」；暗色主题显示太阳，悬停提示「切换到白天主题」。
- 最小化和关闭各宽 42px、与标题栏等高。最小化悬停用 `surface-soft` 底；关闭悬停用 `red` 底、`surface` 色图标（亮色主题下是白色）。窗口不能缩放，所以没有最大化按钮。
- 点关闭把窗口隐藏到托盘，不退出程序；退出走托盘菜单。

标题栏不放页面名称、面包屑、在线状态或刷新按钮。

### 侧边栏

侧边栏只保留六个一级入口，顺序固定如下。

1. 首页
2. 环境
3. 规则
4. 连接
5. 日志
6. 设置

侧边栏 `sidebar` 底，右边 1px `line`，不显示“工作区”等分组标题。入口从顶部往下排，每个入口是 20px 图标加 12px 文字横排，高 40px，圆角约 5.1px。

- 选中项：`accent-soft` 底，图标和文字 `accent`，不加粗。
- 未选中项：图标 `muted`、文字 `ink`，悬停用 `hover` 底。
- 入口可以用 Tab 聚焦，聚焦时显示 1px `accent` 边框；Enter 或 Space 切换页面。
- 切换页面时顺带读取该页需要的数据：首页刷新事件时间线，连接页读连接记录，日志页读运行日志，设置页检查一次 WSL 平台。切到环境页什么都不读。

### 底部状态栏

状态栏横跨窗口全宽，`surface` 底，顶边 1px `line`，从左到右依次如下。

1. 左侧一组五个状态图标。每个是 24px 圆角底块里的 16px 图标，按状态着色（见「颜色」里的状态色）：正常为鲜绿图标加浅绿底，待处理为琥珀图标加浅琥珀底，故障为红色图标加浅红底；未启用只用浅灰图标、不加底色。
   - 后台连接（服务器机柜图标）：在线为正常，未连接为故障。它是唯一能点的状态图标，点击刷新状态或重新连接。
   - 接管状态（盾牌图标）：未接管和状态未知为未启用，接管中为正常，诊断转发为待处理，需要恢复为故障。
   - SQLite 配置（数据库图标）：已加载为正常，待初始化为未启用。
   - DNS（地球图标）：系统 DNS 已接管为正常，未接管为未启用，需要恢复为故障，后台状态未确认和其他未确认状态为待处理。
   - 转发线程（双向箭头图标）：运行正常为正常，故障为故障，没有观测为未启用。
2. 一条竖线后是实时速率：15px 仪表图标，后接「↑ 上行速率」「↓ 下行速率」。
3. 再一条竖线后是累计流量：15px 求和符号图标，后接本次接管以来的「↑ 上行字节」「↓ 下行字节」。
4. 右端是版本号「v版本」，`muted` 等宽字体。

速率和流量不写文字标签，靠图标区分实时和累计；箭头 `muted`，数值用等宽字体，按实际长度排，自动换算 B、KiB、MiB、GiB。没有数据（未接管或后台状态未确认）时显示 0。图标和数值都有悬停提示和读屏标签：提示分行写标题、各项数值和几条说明，例如累计流量注明「应用层字节，不含代理握手和 IP 包头」「重新启动接管后从零计」。除后台连接外的状态图标只读，不进入 Tab 顺序。状态不在侧栏和标题栏重复出现。

### 内容区顶部提示和底部保存栏

内容区在侧栏右边，从上到下是：全局错误条、可滚动的页面内容、保存栏。只有页面内容滚动，其余固定。保存结果用窗口右上角的通知弹出，不占内容区的位置。

- 全局错误条：操作失败时出现在内容区顶部，每个页面都看得到，直到点右端 × 关闭或开始下一次操作。`red-soft` 底、`red` 字、16px 信息图标，只占一行，超长截断，悬停看全文。
- 保存结果通知：规则页、设置页、环境页住宅代理的保存结果，以及保存设置前校验没通过的原因，用 gpui-kit 的 Notification 弹出。通知悬浮在窗口右上角（标题栏下方），不挡页面内容、不随页面滚动，用组件自带的弹出层底色和边框，跟随亮暗主题。成功配 `green` 对勾图标，5 秒后自动消失；失败配 `red` 信息图标，不自动消失，点 × 关闭。同一时间只有一条，新的结果顶替旧的；通知不分页面，保存完成时用户已切到别的页也照样看得到。通知不设类型：设了类型组件会用 `theme.success` 着色的自带图标，这个应用把它设成了浅底色，图标会看不清。
- 提醒通知：和保存结果通知样式相同、位置相同，但编号不同，两种通知互不顶替。用于 UDP 已阻断、换环境时丢掉了没保存的住宅代理修改、托盘「停止全部接管」时没有接管这类提示。警告类（如 UDP 已阻断）配 `red` 信息图标，不自动消失；其余配 `green` 信息图标，5 秒后自动消失。
- 保存栏：只在规则页和设置页出现，`surface` 底，顶边 1px `line`。保存按钮是主按钮、靠右，规则页写「保存规则」，设置页写「保存设置」。有未保存修改时按钮左边显示琥珀色「有未保存修改」标签，上次保存失败时显示红色「保存失败」标签，已保存时不显示标签。有操作进行中或还没拿到配置路径时，保存按钮不可用。

## 页面规范

### 首页

首页回答三个问题：现在有没有在保护、保护的是哪个发行版、链路是否正常，并给出下一步唯一该做的操作。首页不承担 WSL 选择和住宅配置；后台连接、DNS、转发线程的常驻状态在底部状态栏，首页不重复做指标块。

首页分上下两部分，一屏放得下：上面是整行的保护状态卡，下面左边流量卡、右边事件时间线，宽度约 1.6 : 1。

- 保护状态卡（整行）
  - 左侧是 40px 的盾牌状态图标块，颜色规则与状态栏相同：接管中为正常，诊断转发和未知阶段为待处理，需要恢复和后台状态未确认为故障，未接管为未启用（灰图标、`surface-soft` 底）。
  - 中间第一行是一句话状态：未接管、接管中、诊断转发中、需要恢复、后台状态未确认、状态未确认。未接管用正文色，其余用状态色。第二行是一句 `muted` 说明，单行截断：接管中写「目标 的 TCP 和系统 DNS 正经双跳代理出网 · 代次 N」；未接管写哪一页有未保存修改，或者有几个环境配好了住宅代理、到「环境」页选一个启动；后台状态未确认写上次收到状态是多久以前。
  - 右侧只有一个主操作按钮，跟着状态变化：后台状态未确认时「重新连接」；目标发行版已不在注册表里时「放弃本次记录」；其他不处于未接管的阶段（接管中、诊断转发、需要恢复等）时「停止接管」；未接管时「去环境页」。首页不启动接管，也不保存任何内容：启动在各环境的详情里。
  - 后台报告了转发错误时，状态下方显示一条红色提示「最近一次转发错误：…」，单行截断。
  - 有不止一个环境在接管或需要恢复时（决策 40）：一句话状态写成「N 个环境…」并按最差的那个上色；主按钮是「停止全部接管」（确认一次后逐个停止，已注销的环境跳过并在确认框里写明要单独放弃）；卡片下方每个环境一行：名字、阶段标签、入口地址、需要恢复时的原因（换行写全）和它自己的最近一次转发错误，右侧是这个环境自己的按钮（「停止接管」「恢复直连」或「放弃本次记录」）。保护链路的目标节点写「N 个环境」并在悬停提示里列出各环境；入口、住宅出口写「各环境不同」，悬停提示按环境列出；系统 DNS 写「均已接管」或「k/N 已接管」。流量卡和底栏用全部环境的合计。
  - 最下面一行是保护链路：目标 WSL → Windows 入口 → 宿主 SOCKS5 → 住宅出口，一条竖线后是系统 DNS。五个节点等宽，每个是 `surface-soft` 圆角块，分三行：状态圆点加标签；值（等宽字体）；一句状态，未启用时灰色、其余用状态色。接管中显示实际运行的值，接管后又改过的设置在悬停提示里另列「已保存」一行，注明下次启动生效；未接管时显示已保存的共用配置，节点为未启用；目标 WSL 写「未接管」，Windows 入口和住宅出口各环境不同，分别写「—」和「按环境配置」。悬停节点显示明细，例如住宅出口的公网出口核对结果和 UDP 状态，系统 DNS 的 DoH 主机、上游和最近几次启动时测得的延迟。
- 下方左侧：流量卡（标题「流量」，说明「上行 / 下行速率，约 2 秒采样一次」）
  - 一行摘要（等宽字体）：「活动连接 N · 最近 X 秒峰值 ↑ … ↓ …」。
  - 132px 高的面积图展示上行和下行速率，每次状态刷新（约 2 秒）采样一次，最多保留 60 个样本（约 2 分钟）；横轴 5 个刻度，标注样本距现在多久（「刚刚」「N 秒前」）。图下方是图例：亮绿点上行，`ink` 色点下行。
  - 底部隔一条分隔线是路由判定：左边「路由判定」，右边「共 N 次」；下面一条 8px 高的分段横条（直连 `slate`、双跳 `green`、DNS `amber`、拒绝 `red`）和带百分比的图例。TCP 每条连接计一次，UDP 每个数据报计一次，所以这不是流量占比，也不是连接数占比；悬停显示各路由的次数。还没有判定时写「暂无路由样本，产生连接后显示占比。」
  - 没在转发时整张卡只显示一句空态：后台状态未确认时「后台状态未确认，暂停采样。」，未接管时「当前未接管，没有流量。启动接管后开始采样。」
- 下方右侧：事件时间线（标题「事件时间线」，说明「后台运行日志里最新的事件」）
  - 展示后台运行日志里最新的 5 条事件，例如接管开始和停止、预检结果、状态切换，不受日志页筛选影响。
  - 每条两行：消息；`muted` 的「时间 · 目标、阶段、代次」，时间去掉年份。圆点颜色按日志级别：信息绿色、警告琥珀色、错误红色。
  - 读取中、读取失败（红字）、没有事件各显示一句空态；刷新失败但有上次读到的事件时，列表顶部加一行红字说明。

### 环境

环境页面负责每个环境的接管（住宅代理、Windows 入口端口、检测、启动和停止）和管理 WSL 环境（新增、查看详情、编辑组件、改时区、备份、删除）。WSL 平台（wsl.exe 版本与升级）在设置页。预检不单独操作，点「启动接管」时自动执行。

页面左右两栏，中间是可以拖动的分隔条：左栏默认 280px，可在 280–520px 之间调；右栏至少 360px。

- 左栏「WSL 环境」卡：右上角是「新增环境」（小号主按钮）和「刷新列表」（小号描边按钮，读取中显示「读取中…」），下面每个发行版一行。没有发行版时显示空态「没有发现 WSL2 发行版」和「刷新列表后重新读取系统注册信息。」
- 右栏：没点过环境时是「环境详情」空态卡，写「点左侧的环境查看详情。」并提醒读取会启动没运行的发行版；点了某个环境后是环境详情卡；新增或编辑时换成环境表单卡。

每行是 `surface-soft` 底、1px `line` 边框的圆角块：文件夹图标、发行版名称（单行截断）和名称下一行小字的接管状态、右侧这个环境的启停按钮。正在接管（或需要恢复）的行用 `accent-soft` 底、`accent` 边框；正在查看的行用 `selected` 底、`primary` 边框，名称也是 `primary`。行可以用 Tab 聚焦，Enter 或 Space 打开详情。

名称下的小字：正在接管「接管中」，需要恢复「需要恢复」，其余按这个环境有没有保存住宅代理写「未接管」或「未配置住宅代理」。右侧的按钮按这个环境的状态：空闲「启动接管」（主按钮），接管中「停止接管」（描边），需要恢复「恢复直连」，发行版已注销「放弃记录」；点按钮不打开详情。按钮不因为条件不满足而置灰：住宅代理没配置、有页面没保存时，点「启动接管」直接在错误条说明原因。WSL 1 的行右侧只有「WSL 1 不支持」标签。新增、编辑环境和更新时区的结果由结果对话框说明。普通行悬停用 `hover` 灰，绿色底只用于正在接管和正在查看的行。

环境详情卡里，「环境能力」上面是「接管」卡片（`surface-soft` 底）：
- 卡片里不放成段的说明文字：需要说明的地方放一个「ⓘ」图标，鼠标移上去才弹出说明（标题「接管」、协议、Windows 入口端口、住宅代理检测各一个）。
- 标题「接管」，右边一个主按钮，按这个环境自己的状态变化：没在接管时「启动接管」；正在接管时「停止接管」；需要恢复时「恢复直连」；发行版已注销时「放弃本次记录」。停止、恢复、放弃只作用于这个环境，别的环境的接管不受影响。「启动接管」不置灰，不能启动时点了在错误条说明原因。
- 旧版本留下、还没分给任何环境的住宅代理：琥珀底提示一段，写服务器地址和原来的接管目标，下面「分给这个环境」「丢弃」两个小按钮。
- 住宅代理：协议单选（SOCKS5 / HTTP），服务器 IPv4 与服务器端口一行，用户名与密码一行（密码明文显示），Windows 入口端口一行（留空由程序从 43531 起分配）。
- 右下角「保存住宅代理」主按钮，左边按需显示「有未保存修改」或「保存失败」标签。保存只写这个环境；结果用保存结果通知弹出。
- 最下面是住宅代理检测：检测状态标签、多久前检测，右边「检测住宅代理」按钮；下面是检测结论、「直接连接」「经宿主 SOCKS5」两条路各自的结果。检测只用这个环境已保存的住宅代理，点了先弹确认（直接连接会把账号密码不经前置代理发出去）。之后又保存过这个环境的住宅代理或设置页时，旧的检测结果不再显示；换到别的环境时清掉。
- 换到另一个环境时，输入框换成那个环境保存的值；上一个环境没保存的修改丢掉，弹一条提醒说明。

启动前预检发现目标里没有 `nft` 命令时，先弹「安装 nftables」确认框（按钮「安装并继续」）：确认后在目标里以 root 运行 `apt-get install nftables`，装好后自动重新预检；每次启动只问一次，取消则在错误条说明无法启动。

新增环境的表单在默认用户名、默认用户密码下面有「住宅代理」一节（标题旁一个「ⓘ」）：协议单选，服务器 IPv4 与端口一行，用户名与密码一行，和详情里的是同一组输入框。默认用户名、密码和住宅代理四项都填了，「创建并设置」才可点；创建成功后住宅代理自动保存给新环境，入口端口由程序分配。

切到环境页不自动读取环境详情。点左侧某个环境才读取；读取要在该发行版里运行检查，没启动的发行版会被启动。详情卡片右上角的「重新读取详情」再读一次。刷新列表或重连后台后，正在查看的环境已不在列表里时，右侧详情和选中一起清掉。环境页左右两栏高度固定，详情比窗口高时右栏自己滚动。两栏中间只隔着拖动条，挨在一起，所以两栏卡片都不用圆角。

环境详情卡标题「环境详情」，右上角是四个只有图标的按钮，悬停提示写动作：重新读取详情、编辑环境、备份环境、删除环境（红色垃圾桶图标）。内容从上到下：

- 一个 `surface-soft` 块：文件夹图标、名称和「当前目标」（绿）或「未分配」（灰）标签；安装位置（等宽字体，单行截断）和「打开安装位置」按钮；下面是系统信息。
- 系统信息是一组可换行的小块，每块上面是 `muted` 名称、下面是等宽字体的值：WSL 版本、发行版、时区（右上角铅笔按钮打开「设置时区」对话框）、Locale、内核、架构、默认用户（`/etc/wsl.conf` 里 `[user] default`，没写时显示「wsl.conf 未指定」）、图形界面（WSLg 可用 / WSLg 缺 X11 套接字 / WSLg 不可用）、磁盘已用/上限（虚拟磁盘按需增长，上限不是 Windows 盘上实际占用）。
- 环境能力和接管基础各是一组可换行的 `surface-soft` 块：名称和状态标签在同一行，下一行写用途，缺东西时改写缺了什么。
- 环境能力：zsh（终端工具）、Chrome（图形浏览器和 chrome 启动器）、中文输入法（fcitx5 拼音和 zh_CN 语言包）三项，标签为「已就绪」（绿）、「需要补齐」（琥珀）、「手动安装」「未安装」或「未读取」（灰）。需要补齐时第二行列出缺什么，例如旧版本建的环境「缺 GTK 输入法模块；输入法启动脚本是旧版」「chrome 启动器是旧版，Chrome 语言是 zh-CN」；任一项需要补齐时，下方用琥珀色提示「编辑 → 保存设置」会按当前版本重装勾选的组件，并写明保存会重启该发行版、装了 Chrome 或中文输入法时系统语言会改成 en_US。程序在、但本工具写的文件（输入法启动脚本、chrome 启动器）不在时标「手动安装」，第二行写「非本工具安装：缺 …」，不给补齐提示——补齐会跑 apt、把系统语言改成 en_US 并重启发行版，不该推给自己装软件的人。
- 接管基础：systemd（运行中为绿；未运行、未开启为琥珀，第二行写怎么处理）、iptables-legacy、ip6tables-legacy（已安装为绿，未安装为琥珀），下方注明「这里只列组件在不在；能不能接管以预检结果为准」。环境详情不给「可以接管」这类结论。

后台没返回某一项（旧版后台）时显示「未读取」，不当成未安装。

新增和编辑用同一张表单卡，显示在右栏，标题「新增 WSL 环境」或「编辑 WSL 环境」：

- 新增：环境名称、发行版（从微软官方 WSL 发行版列表里选，下拉框可搜索）、安装目录（填父目录，右边「选择目录」按钮；下方显示自动拼出的实际路径）、默认用户名、默认用户密码（可切换显示）。名称旁的 ⓘ 悬停说明命名规则。
- 编辑：环境名称只读显示，注明「发行版名称不可在此修改。」
- 两种都有「安装组件」三个勾选框：安装 zsh、安装 Chrome、中文输入法。编辑时已装的组件保持勾选、不能取消，下方用琥珀色提醒保存会开启 systemd 并重启该发行版，另起一行提醒勾了 Chrome 或中文输入法时保存会把系统语言设为 en_US（LANG=en_US.UTF-8、LANGUAGE=en_US:en）。
- 底部右侧是「创建并设置」或「保存设置」（主按钮）和「取消」。

备份、改时区、删除走对话框，见「对话框」。新增、编辑、更新时区、删除的过程和结果也用对话框显示。

### 规则

规则页面用于维护直连例外，只有一张「直连规则」卡，说明「每行一个；命中任一条的 TCP 连接直连，不走代理链；UDP（含 QUIC）一律走代理链。」三类规则固定并排三列，每列是一个 `surface-soft` 圆角块：标题、多行输入框、一句 `muted` 说明。

- IPv4 / CIDR：例如 192.0.2.0/24。
- 精确域名：每行一个域名，不填写 URL。
- 域名后缀：按域名边界匹配。

每行一个值，输入区域使用统一输入框样式。规则卡片占满整页高度，三列输入框随窗口一起拉高，最矮 112px；窗口太矮放不下时整页滚动。规则页只有这一张卡片，不显示配置文件路径和后台提示。「保存规则」按钮放在页面底部的固定保存栏里，只保存这三类直连规则；保存栏和保存结果通知见「内容区顶部提示和底部保存栏」。

### 连接

连接页面展示连接记录，并放出口复核和诊断导出这几个排查操作。页面占满内容区高度，从上到下：

1. 右上角一组小号按钮：「复核公网出口」（只在接管中可用）、「导出脱敏诊断」、「重置 DNS 别名」（只在未接管时可用，点了先确认）、「打开报告位置」（导出过报告后可用）。复核和重置有悬停说明。
2. 一行指标块（`surface-soft`，上面 `muted` 名称、下面等宽字体的值）：进行中、已记录、已记录失败（大于 0 时 `red`）、UDP（经代理链为 `green`，未接管为 `muted`，其余 `red`）、公网出口。公网出口块占两份宽度，名称写「公网出口 · 多久前检测」，值写「IP · 国家 · 已匹配 / 未匹配 / 未比对」，已匹配 `green`、未匹配 `amber`，没检测过写「未检测」；悬停说明结果只代表那一次观测。
3. 需要时显示单行提示条，悬停看全文：后台报告的最后一次转发错误（红）；本次后台运行期间有连接没能写入 SQLite（琥珀）；刷新连接记录失败、下面是上次的结果（琥珀）。
4. 「连接记录」卡，占满剩下的高度：
   - 标题行：「连接记录」，接着是 `muted` 的保留说明「保留最新 N 条；记录目的 IP 和端口，不含域名和内容。」，右边是「全部 / 进行中 / 失败」筛选，默认「全部」。
   - 环境筛选行：「环境」，后面是「全部环境」和每个环境名一个按钮，可换行。
   - 表格列：环境、协议、目的端 · 判定原因、路由、状态 · 阶段、上行 / 下行、结束时间 · 时长。后两列右对齐。每格两行，第二行 `muted`：目的端（等宽字体）下面是判定原因，例如「默认双跳」「域名例外」「系统 DNS」「并发已满」；状态下面是阶段，只有进行中和失败的连接显示阶段；结束时间下面是时长，还没结束的写「进行中」（`accent`）或「刚结束」。协议、流量、时间用等宽字体。
   - 路由用标签：直连 `slate`、双跳 `green`、DNS `amber`、拒绝 `red`、待判定灰色。状态文字：活动 `accent`、完成 `ink`、失败 `red`、已停止 `muted`。
   - 行高 48px，悬停 `surface-soft` 底；表格区自己滚动。进行中的连接（来自后台状态快照）排在前面，已结束的来自 SQLite；同一条两边都有时以 SQLite 为准。有更早的记录时底部显示「加载更早」。
   - 没有行时不显示空表格行，表头下方居中一句空态，按筛选和状态区分，例如「当前未接管，没有进行中的连接。」「还没有连接记录。连接结束后会保存在这里。」读取中、读取失败也各有一句。

### 日志

日志页面是一张「运行日志」卡，说明「后台事件、预检结果和接管生命周期，数据保存在 SQLite」。

- 工具行：左侧 240px 搜索框，提示「搜索消息、来源或目标」，输入即搜索；右侧「全部 / 错误 / 警告」筛选和「刷新」，都是小号描边按钮，当前筛选高亮。
- 计数行：「共 N 条；最新的在顶部」；只显示了一部分时写「显示最近 N 条，共 M 条；最新的在顶部」。刷新失败但还有上次读到的日志时，这一行改成红字说明。
- 表格列：时间（等宽字体，`muted`）、级别、事件、来源（`muted`）。事件分两行：消息，下面一行 `muted` 的上下文（目标、阶段、代次）。行高 54px；列表区高 420px（窗口高 700 减去 280），自己滚动。
- 级别标签：信息绿色、警告琥珀色、错误红色。
- 有更早的日志时底部显示「加载更早」。
- 没有日志时在列表区居中显示一句：正在读取运行日志…、读取运行日志失败（红字）、暂无错误记录、暂无警告记录、暂无运行日志。

### 设置

设置页面承载各环境共用的代理链、DNS 和本机配置（住宅代理和 Windows 入口端口按环境保存，在环境页），用 gpui-kit 的 Settings 组件排版：外面一个带边框的面板，左边是分区导航（默认 180px，可在 160–240px 之间拖动；顶部带搜索框，按设置项名称过滤），右边显示当前分区；分区内每项左边是名称，输入框或值紧跟在名称后面：名称栏至少 160px，同一分区的输入框左边对齐，更长的名称只撑宽自己那一行；分区窄于 480px 时改成上下排，名称在上、内容占满一行。输入框沿用页面自己的输入状态，底部「保存设置」保存所有分区的字段，不只是当前看到的分区。分区依次是：

- 网络与 DNS：分四组。
  - 「网络入口」：宿主 SOCKS5（IPv4:端口）。
  - 「受管 DNS」：DoH 上游 IPv4:端口、TLS 主机名、健康检查域名。
  - 「白名单域名解析」：国内 DoH 上游 IPv4:端口、国内 DoH TLS 主机名，说明命中域名白名单的查询由 Windows 直接问这个国内 DoH、连不上时仍经代理链、上游留空即关闭。
  - 「远端解析」：勾选框「白名单以外的域名由住宅代理解析」，随「保存设置」保存，说明下次启动接管时生效。
  - 左侧导航在这个分区下列出各组，点击跳到对应的组。
- 转发限制：并发 TCP 上限（条）、TCP 空闲断开（秒）、半关闭等待（秒），留空用默认值 256、1800、60；分组下方注明下次启动接管时生效。
- 桌面运行：「开机自动启动」勾选框，勾选立即生效、不用保存；下面是只读的几行：关闭窗口「隐藏到托盘」、托盘退出「停止接管并关闭后台」、配置库「SQLite」、配置状态（已加载 / 待初始化）、Revision。
- WSL 平台：说明「wsl.exe 与共享的 WSL2 内核；发行版本身在「环境」页管理。」
  - 顶部：状态标签和多久前检查，右边「检查」和「升级 WSL」（主按钮，只在未接管时可用）。每次进入设置页自动检查一次。
  - 两列只读信息：WSL 版本、WSL2 内核、Windows 版本、wsl.exe 路径；默认版本、默认发行版、发行版数量（含几个 WSL1）、权限（管理员 / 标准用户）。
  - 下面是逐项检查结果（绿色对勾，或琥珀、红色信息图标）、上次升级的结果和一段说明：检查只读，升级运行 `wsl --update`、可能重启 WSL。
- 关于：放在最后。
  - 顶部：48px 的应用 logo，右边依次是应用名「WSL Proxy」（常规字重，加粗只留给标题栏）、「版本 x.y.z」和一句产品说明。
  - 下面是只读的几行：组成（桌面端 wsl-proxy-desktop.exe 和后台 wsl-proxyctl.exe，需同一版本、放在同一目录）、运行平台（Windows 和 CPU 架构）、配置库路径（等宽字体，过长时截断，悬停显示完整路径）。
  - 版本号是桌面端编译时的版本。后台状态里没有版本号，这里不显示正在运行的后台的版本。

设置项的名称在左、输入框（横排时固定宽度）或值在右，由 Settings 组件排版；只读值用 `muted` 颜色。WSL 平台分区是整块自定义内容，里面的只读信息沿用「名称 值」的行（行高至少 38px，底部分隔线，名称列宽 112px）。和规范的两处出入：Settings 每个分区顶部自带分区标题（12px、常规字重），左侧导航里选中的那一项是中等字重，组件没有开关可以关掉。

配置在页面直接填写并保存到 SQLite，不使用导入流程。「保存设置」在页面底部的固定保存栏里，只保存本页的代理链、DNS 和转发限制。保存成功、保存失败或保存前校验没通过时，结果用窗口右上角的保存结果通知弹出，不弹全局错误条；规则页同样如此。个人使用模式允许在环境页直接查看住宅服务器、端口、用户名和密码。

## 组件规范

### 卡片

卡片使用 `surface` 背景、1px `line` 边框、约 5.1px 圆角、约 10.3px 内边距，卡片里的区块间距也是约 10.3px。卡片头部左右分布：左边是标题，下面可以有一行 `muted` 说明；按钮或状态标签在右边。卡片标题和正文一样是 12px 常规字重。

卡片里的次级块（指标块、链路节点、环境信息块、规则列、空态）用 `surface-soft` 底、约 5.1px 圆角，不加边框。

### 按钮

按钮文字 12px 常规字重，普通高度约 27.4px，小号约 20.6px，圆角 10px。带图标时图标 15px：主按钮上的图标和文字同色，其他按钮上的图标 `muted`。

- 主按钮：`primary` 底、`surface` 色文字（亮色主题是森林绿底白字，暗色主题是亮绿底深色字），悬停 `accent`，按下 `primary-pressed`。用于每个场景里唯一的主要动作：首页的主操作，「保存规则」「保存设置」「保存住宅代理」「启动接管」「停止接管」「新增环境」「创建并设置」「升级 WSL」，以及对话框里的确认。
- 描边按钮：「刷新列表」「加载更早」「选择位置」，以及日志页、连接页的筛选。当前选中的筛选高亮。
- 默认按钮：「检测住宅代理」「检查」「复核公网出口」「导出脱敏诊断」「重置 DNS 别名」「打开报告位置」「选择目录」，以及表单和对话框里的「取消」「关闭」。用组件库默认样式，没按应用色板单独设色，颜色需截图确认。
- 只有图标的按钮：标题栏主题切换、环境详情右上角四个操作、时区旁的铅笔、打开安装位置、错误条的关闭。透明底，必须有悬停提示和读屏标签写清动作。
- 危险按钮：只有「删除环境」确认框里的「删除」。用组件库默认的危险红，不是应用的 `red`，颜色需截图确认。

### 输入框

输入框和下拉框高约 27.4px，圆角 10px，1px `line-strong` 边框，聚焦时显示组件库的焦点线，主题焦点色设为 `accent`（实际效果需截图确认）。输入框里的文字不用等宽字体。规则页多行输入框最矮 112px、随窗口拉高。密码：环境表单的默认用户密码默认遮住、可切换显示；环境页住宅代理密码明文显示。有操作进行中、正在读取或有确认框没处理时，可编辑的输入框和会改动状态的按钮都不可用。

字段名写在输入框上方。环境表单的字段名用 `ink`，多数旁边有 14px 的 ⓘ，悬停显示填写说明；设置页的字段名在输入框左边，由 Settings 组件排版，输入框里的占位文字写格式，例如「宿主 SOCKS5：IPv4:端口」「留空为默认 256」。

### 标签和状态

标签是胶囊形：浅色底，左边一个 6px 同色圆点，文字 12px 常规字重。

| 含义 | 文字色 | 底色 | 例子 |
| --- | --- | --- | --- |
| 正常 | `green` | `green-soft` | 已就绪、已安装、运行中、信息、双跳 |
| 待处理 | `amber` | `amber-soft` | 需要补齐、未开启、有未保存修改、警告、DNS |
| 错误 | `red` | `red-soft` | 保存失败、WSL 1 不支持、错误、拒绝 |
| 选中 | `accent` | `accent-soft` | 当前目标 |
| 直连 | `slate` | `slate-soft` | 直连 |
| 中性 | `muted` | `surface-soft` | 未读取、手动安装、未分配、待判定 |

状态标签只写短状态，详细说明放在相邻文字或悬停提示里。

### 悬停提示

纯文字提示最宽 280px，超出自动换行。状态栏图标和数值、保护链路节点、路由判定用分行提示：第一行标题，下面几行「名称（`muted`）　数值（等宽字体）」，最后几条 `muted` 说明。

### 图标

图标都是线性 SVG，颜色由使用处指定。尺寸：导航 20px；状态栏状态图标 16px（放在 24px 底块里）；状态栏速率和流量 15px；按钮 15px；标题栏应用图标 23px、主题切换 16px；首页保护状态 22px；空态 24px；字段说明 ⓘ 14px；错误条和保存结果通知 16px。

### 对话框

对话框都带遮罩，标题 12px 常规字重。对话框底色取组件库的背景色，需截图确认。

- 确认框：一段说明文字，「取消」和写明具体动作的确认按钮，按 Esc 可以关闭。
  - 启动接管、停止接管、放弃本次记录、重置 DNS 别名：标题「确认保护操作」，按钮「确认并执行」。启动接管的说明写明会接管目标的 TCP、UDP 和系统 DNS，只有直连例外的 TCP 直连，接管前会把目标时区改成住宅出口所在时区并重启目标、其中正在运行的程序都会被结束。桌面没有切换目标的入口。
  - 预检发现缺内核能力：标题「准备内核环境」，按钮「加载并继续」。
  - 设为接管目标：标题「设为接管目标」，按钮「确认并保存」，说明写清是否影响正在进行的接管。
  - 删除环境：标题「删除环境」，按钮「删除」，危险样式。
  - 升级 WSL 平台：标题「升级 WSL 平台」，按钮「升级」。
  - 检测住宅代理：标题「检测住宅代理」，按钮「检测」，说明用的是这个环境已保存的住宅代理。
  - 托盘退出时联系不上后台：标题「联系不上后台」，按钮「仍然退出界面」。
  - 托盘退出时后台已经不在、而它最后报告的状态不是空闲：标题「后台已经不在运行」，按钮同为「仍然退出界面」。
- 进度框（宽 440px）：有操作或读取在进行时自动弹出，结束时自动关闭；不能手动关闭，不响应 Esc。标题写在做什么，例如「创建环境」「安装组件」「更新时区」「删除环境」「升级 WSL 平台」「启动前检查」「读取环境详情」。创建和编辑环境时显示后台报告的阶段、百分比进度条和步骤清单，没选的组件标「未选择」；后台还没报告进度时只显示进行中的动画条和已用时间，不按时间猜进度。
- 结果框（宽 520px）：环境创建、编辑、删除、更新时区、WSL 升级的结果。成功用 22px 绿色对勾，失败用红色信息图标，只有「知道了」。
- 表单框（宽 520px，不响应 Esc，点遮罩不关闭）：
  - 备份环境：备份文件路径、「选择位置」，底部「取消」和「开始备份」。
  - 设置时区：按国家分组、可搜索城市或时区名的下拉框，琥珀色提醒保存会重启发行版，底部「取消」和「保存时区」。
  - 校验错误用红字显示在框内。
- 备份完成框（宽 520px）：显示备份文件路径（等宽字体），「关闭」和「打开备份位置」；Esc、点遮罩都能关闭。

### 状态岛

多个环境在接管时（决策 40），收起时的速率是全部在转发的环境之和；展开后每个环境一行：名字、出口（IP 和国家，是否与住宅地址一致用颜色表示；没测过写「未检测」，需要恢复的写「需要恢复」并用故障色）和上下行速率，最多 3 行，再多的最后一行写「另外 N 个环境，打开主窗口查看」。这时不列应用。只有一个环境时和以前一样。

### 托盘

程序运行时在通知区域显示托盘图标。单击或双击打开主窗口。

- 图标：盾牌加一条白色心电波形，按通知区域的实际尺寸绘制（100% 缩放时 16px）。盾牌颜色跟状态栏的状态色一致：未接管灰色（`#86938B`，比状态栏的未启用灰深一档，浅色任务栏上也看得清）、接管中绿色、诊断转发中琥珀色、需要恢复红色。后台状态未确认（后台没连上、状态缺字段或阶段未知）时是琥珀色盾牌加一条平线，不画成未接管：这时接管可能仍在生效。托盘不跟随界面的白天、黑夜主题。
- 动效：只有接管中会动，一道亮光沿波形从左往右循环扫过，约 1.8 秒一圈，亮光以外的波形调暗；其余状态都是静止图标。启动、停止的过程中图标不另加动效。
- 悬停提示：第一行「WSL Proxy」，第二行状态，接管中、诊断转发中、需要恢复时带发行版名，例如「接管中 · Ubuntu-24.04」；有操作在进行时第三行写「正在启动接管…」这类，等确认时写「等待在主窗口确认」。
- 右键菜单（位置固定，只换主操作的文字和置灰状态）：
  1. 灰字状态行，同悬停提示的第二行；有操作在进行或等确认时，下面再加一行灰字说明。
  2. 打开 WSL Proxy（加粗，默认项）。
  3. 主操作：后台状态未确认时「重新连接后台」；目标已不在 WSL 注册表里时「放弃本次记录」；需要恢复时「去恢复接管」（打开那个环境的页面）；接管中、诊断转发中时「停止全部接管」（确认一次，然后按顺序逐个停止每个在接管或需要恢复的环境；有一个没停下来就不再往下停）；未接管时「打开环境页」。托盘不启动接管。
  4. 检测公网出口：只有接管中可点。
  5. 查看连接记录、查看运行日志：打开对应页面。
  6. 开机自动启动：勾选框，点了立即生效，不打开窗口；改不了时把窗口叫出来，在错误条说明原因。
  7. 退出。
  - 有操作在进行或等确认时，会发请求的项（重新连接、停止、放弃、检测出口）置灰；打开页面的项和退出照常可点，退出由界面说明为什么现在不能退出。
  - 除「打开 WSL Proxy」和「开机自动启动」外，点菜单项都会先把主窗口叫出来，确认框和结果在窗口里显示。菜单按点开那一刻的状态生成，点下去时界面会再检查一次，状态已经变了就在错误条说明。

## 交互规范

- 点击侧边栏入口只切换当前页面，不改变其他页面的填写内容。
- 启动接管：点环境详情「接管」卡片里的「启动接管」后，先检查各页有没有未保存修改、这个环境有没有保存住宅代理；然后自动预检（进度框「启动前检查」），预检只读，不写规则；通过后弹确认框，确认了才启动。预检发现目标内核缺少所需能力时，先弹「准备内核环境」确认框，确认后加载模块并自动重新预检，取消则在错误条说明缺这些能力时无法启动。目标的 WSL 内核低于 6.18.58.1 时不弹这个框，错误条提示到「设置 › WSL 平台」升级 WSL。预检没通过时在错误条里写阻断原因。启动成功后提示目标时区已改成哪个时区、目标已重启。
- 停止接管、放弃本次记录：直接弹确认框。
- 确认框可以按 Esc 关闭。
- 每页只保存本页的内容：规则页「保存规则」只存直连规则，设置页「保存设置」只存设置页的字段，环境页「保存住宅代理」只存正在看的那个环境的住宅代理和入口端口。没保存的输入只在它所在的页显示「有未保存修改」，保存失败也只在那一页显示「保存失败」，三页使用同一种标签样式。任一页有未保存修改时不能启动接管，提示会指明是哪一页。
- 操作失败时，内容区顶部显示红色错误条，可以关闭；备份、时区等对话框里的校验错误显示在对话框内。
- 保存设置前校验端口和转发限制，没通过时用保存结果通知写原因。保存成功的提示写「设置已保存；不会立即改变当前接管。」，新的 Revision 显示在「桌面运行」分区。环境页住宅代理四项都空表示还没配置，可以照常保存，但这个环境不能启动接管。
- 状态栏图标通过悬停提示完整状态文字。
- 导航项和环境行可以用 Tab 聚焦，聚焦时显示 `accent` 边框，Enter 或 Space 激活；按钮和输入框用组件库的焦点样式。
- 关闭窗口隐藏到托盘。托盘「退出」：未接管或状态未知时直接请求关闭后台，成功后退出；有环境在接管或需要恢复时先确认停止全部接管（确认框列出这些环境），逐个停止成功、全部回到空闲后再关闭后台并退出。任何一步没成功，程序都不退出，并在错误条说明原因；联系不上后台时询问是否只退出界面。

## 实现验收

- 标题栏、侧边栏、主内容区和状态栏边界清晰。
- 除首页流量图的坐标轴刻度和悬停数值外，所有文字为 12px；只有应用标题加粗。
- 卡片之间、卡片内主要区块之间的间距一致。
- 六个侧边栏入口均能用鼠标和键盘切换到对应页面。
- 首页的保护状态卡、流量卡和事件时间线在 980 × 700 窗口内一屏放得下。
- 亮色和暗色主题下，文字、标签和状态色都看得清。
- WSL 发行版选择只出现在环境页面。
- 住宅配置只出现在设置页面，直接填写并保存到 SQLite。
- 规则页面只维护直连例外。
- 无数据页面显示清晰空态，不使用示例数据或虚假运行状态。
