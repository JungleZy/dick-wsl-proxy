# WSL Proxy UI 设计规范

## 文档范围

本规范对应已确认的 HTML 设计原型，覆盖桌面窗口外壳、首页监控、环境、规则、连接、日志和设置页面。Windows 桌面实现使用 `gpui-kit 0.10.0` facade，页面、组件和交互以本规范和原型为基准。

相关文件如下。

- [HTML 设计原型](./ui-redesign-html.html)
- [首页预览图](./ui-redesign-html.png)

HTML 原型已实现页面切换、启动确认对话框、规则保存反馈和 `Escape` 关闭对话框。GPUI 实现已接入环境目标与见证操作、预检、环境创建编辑备份、日志入口、SQLite 保存和自定义标题栏。

## 设计原则

- 首页优先展示运行监控和关键健康指标。
- 所有页面使用同一套字号、间距、颜色和控件规则。
- 应用标题保留唯一的突出层级，正文区域保持常规字重。
- 状态集中在底部状态栏，以图标承载状态，悬停显示文字说明。
- 配置直接在页面填写，个人使用场景允许明文查看住宅配置，数据由 SQLite 保存。
- 页面结构保持克制，避免重复状态、重复标题和无实际作用的装饰。

### 字体

- UI 字体使用 `Inter`，回退到 `Microsoft YaHei UI` 和 `Segoe UI`。
- 数值、端口、百分比和图表坐标使用 `IBM Plex Mono`，回退到 `Consolas`。
- 应用标题 `WSL Proxy` 使用 16px、700 字重。
- 页面中其他文字统一使用 14px、400 字重。
- 不通过字号或加粗制造卡片内的层级差异，使用颜色、留白、边框和位置表达层级。

## 应用外壳

### 标题栏

标题栏横跨窗口全宽，包含应用盾牌图标、`WSL Proxy` 应用标题、设置图标和窗口控制按钮。标题栏不放页面名称、面包屑、在线状态或刷新按钮。

### 侧边栏

侧边栏只保留六个一级入口，顺序固定如下。

1. 首页
2. 环境
3. 规则
4. 连接
5. 日志
6. 设置

侧边栏不显示“工作区”等分组标题。每个入口由 20px 图标和 14px 文字组成，图标与文字之间使用 12px 间距。选中态使用 `blue-soft` 背景和 `blue` 图标颜色，不使用加粗。

导航容器左右内边距为 12px，普通入口左右内边距为 14px。未选中图标使用 `muted` 颜色，选中图标与文字使用 `blue` 颜色。窄侧栏入口取消文字和入口内边距，图标在 72px 侧栏中居中。

### 底部状态栏

状态栏横跨窗口全宽，只显示图标按钮。当前状态顺序如下。

1. 后台在线
2. 未接管
3. SQLite 配置已加载

图标按钮保留 `title` 和 `aria-label`，悬停或辅助技术读取时显示完整文字。状态不在侧栏、标题栏或页面头部重复出现。

## 页面规范

### 首页

首页用于监控运行状态，不承担 WSL 选择和住宅配置。

首屏上方使用两列卡片布局，左侧内容宽度约为右侧的 1.6 倍。

- 运行状态
  - 标题为“运行状态”。
  - 右上角放带播放图标的“启动接管”按钮。
  - 不显示“未接管 / IDLE”独立状态行。
  - 下方保留当前目标、运行代数和 DNS 三个指标块。
- 流量与健康
  - 展示入口、工作线程和最近错误。
- 保护路径
  - 展示下一跳、系统 DNS 和 SQLite 配置状态。
- 最近操作
  - 展示后台连接、预检提醒和窗口行为。

监控图表位于上方状态卡片下方，使用两列布局。

- 流量趋势
  - 折线展示入口流量和转发流量。
  - 横轴使用 00、04、08、12、16、20、24。
  - 蓝色表示入口流量，绿色表示转发流量。
- 连接路由
  - 使用横向条形图展示直连、住宅链路、DNS 和拒绝。
  - 条形图右侧显示百分比。
- DNS 健康
  - 使用折线展示 DoH 响应延迟。
  - 展示示例中位延迟和最近检查趋势。
- 事件时间线
  - 展示后台心跳、配置加载和预检等待事件。

HTML 原型中的图表明确标记为示例数据、示例分布或示例趋势。实际实现接入运行数据后，应替换这些标识，并在无数据时显示空态。

### 环境

环境页面负责选择 WSL 目标和见证，并配置 Windows 入口端口。

- WSLProxyLab-Target
- WSLProxyLab-Control
- Windows 入口端口
- 环境基线
- 预检
- 端口占用
- 环境管理
  - 新增 WSL 环境
  - 查看环境能力
  - 编辑 zsh、Chrome 和中文输入法选项
  - 备份环境到新的 rootfs tar 文件

目标和见证使用独立的目标行，每行右侧放置对应操作按钮。预检只执行只读检查，不直接写入规则。

环境管理使用独立卡片承载生命周期操作。新增和编辑使用同一套表单，备份路径单独填写，操作过程中保留明确的创建、保存、取消和选择路径入口。

### 规则

规则页面用于维护直连例外，字段分为三列。

- IPv4 / CIDR
- 精确域名
- 域名后缀

每行一个值，输入区域使用统一输入框样式。保存按钮放在卡片右上角，保存后显示短暂的“已保存”反馈。

### 连接

连接页面展示活动流量和连接记录。

- 顶部为活动、最近连接和 DNS 三个运行指标。
- 下方为连接记录表格。
- 无数据时显示居中的空态，不显示空表格行。
- 表格列为 ID、协议、目的、路由和阶段。

### 日志

日志页面展示后台事件、预检结果和接管生命周期。

- 表格列为时间、级别、事件和来源。
- 右上角提供“全部”和“错误”筛选入口。
- 信息状态使用绿色标签，待处理状态使用琥珀色标签。

### 设置

设置页面承载所有住宅和本机配置。

- 住宅 SOCKS5
  - 服务器 IPv4
  - 端口
  - 用户名
  - 密码
- 宿主 SOCKS5
- DNS 保护
- 存储
  - 显示 SQLite 状态、revision 和草稿保存状态
- 窗口

配置在页面直接填写并保存到 SQLite，不使用导入流程。个人使用模式允许在页面直接查看住宅服务器、端口、用户名和密码。

## 组件规范

### 卡片

卡片使用白色背景、1px `line` 边框、10px 圆角和 12px 内边距。卡片头部采用左右分布，标题和辅助说明在左侧，按钮或状态标签在右侧。

### 按钮

- 普通按钮使用浅灰背景和 `line-strong` 边框。
- 主按钮使用 `blue-dark` 背景和白色文字。
- 危险按钮使用 `red` 背景和白色文字。
- 启动、保存等有明确动作的按钮可以带 15px 图标，图标与文字间距为 7px。
- 按钮文字保持 14px、400 字重。

### 输入框

输入框高度为 32px，左右内边距为 12px，圆角为 6px。聚焦时使用 `blue` 边框和低透明度蓝色外发光。端口和协议数值使用等宽字体。

### 标签和状态

标签使用胶囊形背景，保持 14px、400 字重。正常状态使用绿色，待处理状态使用琥珀色。状态标签只表达短状态，详细说明放在相邻文字或悬停提示中。

### 图标

图标使用线性 SVG 风格，默认继承文字颜色。导航图标保持 20px 正方形，按钮图标保持 15px，状态栏图标保持 17px。图标与文字共享同一基线，不单独增加垂直偏移。

## 响应式规则

- 宽度大于 1050px 时，首页状态区域和图表区域使用两列布局。
- 宽度不超过 1050px 时，首页、策略和设置相关网格切换为单列，内容区继续垂直滚动。
- 宽度不超过 800px 时，侧栏收窄为 72px，只保留图标，指标和表单切换为单列。
- 所有页面内容放在主内容滚动区，窗口底部状态栏保持固定可见。
- 图表使用 `preserveAspectRatio="none"` 适配卡片宽度，坐标和图例不得溢出卡片边界。

## 交互规范

- 点击侧边栏入口只切换当前页面，不改变其他页面的填写内容。
- 点击“启动接管”打开确认对话框。
- 按 `Escape` 关闭确认对话框。
- 点击“保存规则”显示短暂的保存反馈。
- 保存住宅配置时校验端口，成功显示保存状态和 revision，失败显示可读错误。
- 状态栏图标通过悬停提示完整状态文字。
- 页面按钮、输入框和表格行保留键盘焦点样式。

## 实现验收

- 标题栏、侧边栏、主内容区和状态栏边界清晰。
- 页面中除应用标题外所有文字为 14px、400 字重。
- 页面主要区块间距统一为 12px。
- 六个侧边栏入口均能切换到对应页面。
- 首页四个监控图表在宽窗口和窄窗口下均可读。
- WSL 选择只出现在环境页面。
- 住宅配置只出现在设置页面，直接填写并保存到 SQLite。
- 规则页面只维护直连例外。
- 无数据页面显示清晰空态，不使用虚假运行状态。
