# WSL Proxy UI 审核结论

> 这是早期的一次审核记录，内容已不代表现状：窗口尺寸、侧栏宽度、字号、状态栏、首页和各页面布局都已变化。现行界面见 [ui-design-spec.md](./ui-design-spec.md)，最近一次审查见 [docs/discussions/2026-11-23-桌面端UI审查-48c3aa0及未提交改动.md](../docs/discussions/2026-11-23-桌面端UI审查-48c3aa0及未提交改动.md)。

## 审核范围

本次审核以 `ui-redesign-html.html` 和 `ui-design-spec.md` 为基准，检查桌面外壳、侧边栏、状态栏、首页监控、环境页面、规则、连接、日志和设置页面。

## 结论

- 桌面实现已迁移到 `gpui-kit 0.10.0`。
- 标题栏高度为 42px，默认窗口为 1120×720px，最小窗口为 800×620px。
- 侧边栏宽度为 216px，窄窗口收窄为 72px。导航容器左右内边距为 12px，入口高度为 40px，图标为 20px，图标与文字间距为 12px。
- 导航图标、标题栏应用图标、启动图标和底部状态图标统一使用设计稿线性 SVG。底部状态栏高度为 34px，状态图标为 17px，并通过悬停提示和辅助标签提供完整文字。
- 首页只负责运行监控，展示运行状态、流量健康、保护路径、最近操作、流量趋势、连接路由、DNS 健康和事件时间线。没有真实样本时，图表显示空态，不填充示例数据。
- 环境页面承担 WSL 目标、预检、端口和环境生命周期操作。发行版信息与操作按钮分行显示，窄窗口不会压缩名称。
- 规则页面维护直连例外。住宅 SOCKS5、宿主 SOCKS5、DNS、SQLite 和窗口行为统一放在设置页面。
- 配置直接在页面填写并保存到 SQLite。项目根目录 `.env` 仅用于首次读取默认住宅配置，页面允许个人用户直接查看配置内容。
- 页面正文保持 14px 常规字重，只有标题栏应用标题使用突出字重。
- 首页、环境和规则的双列区域使用最小可读宽度和自动换行，在窄窗口中转为纵向布局。

## 交互审核

- 六个导航入口支持鼠标、键盘焦点、Enter 和 Space 激活。
- 启动接管使用确认对话框，取消和确认按钮均可操作。
- 环境新增、编辑和备份操作在后台回复后刷新状态，写操作前检查当前运行状态。
- 日志提供全部和错误筛选，待处理状态使用琥珀色标签。
- 设置保存提供草稿、成功和失败状态提示，端口在发送前校验范围。
- 底部未接管和 SQLite 状态图标为禁用状态，不进入键盘 Tab 顺序。后台在线图标保留刷新操作。

## 验证结果

- `cargo check -p wsl-proxy-desktop` 通过。
- `cargo clippy --workspace --locked --all-targets -- -D warnings` 通过。
- `cargo test --workspace --locked` 通过，5 个库测试和 106 个控制器测试全部通过。
- `python -m unittest discover -s scripts -p 'test_package_windows.py'` 通过，2 个打包测试通过。
- `scripts/build-desktop-windows.sh` 通过，生成 Windows x64 原生发布版桌面程序和控制器。
- `bash -n scripts/build-desktop-windows.sh` 和 `git diff --check` 通过。
- 原生 Windows 窗口已检查首页、环境、日志和设置页面，侧边栏宽度、图标、状态栏和环境行布局与设计规范一致。
